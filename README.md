# Tic-Tac-Toe

A Django game with local two-player and bot modes. Choose a bot difficulty and player mark; the starting player alternates between local games.

## Run locally

1. Create and activate a Python virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Start the app with `python manage.py runserver`.
4. Open http://127.0.0.1:8000/.
